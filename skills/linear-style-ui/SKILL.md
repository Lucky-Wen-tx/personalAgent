# Linear 官网风格设计

## 输入
- 必需：页面类型（落地页 / 产品页 / 定价页 / 文档站）与一句话描述目标受众；现有截图或代码（有则优先审查，无则从零出规范）。
- 可选：品牌色是否需要替换靛紫、是否需要浅色主题、是否已有设计系统。
- 缺失时：页面类型不明 → 停下问，不同页面类型的字号与间距档位不同；品牌色未给 → 用 `#5e6ad2` 并标「品牌色待确认」；浅色主题未说明 → 只出暗色，标注「浅色未覆盖」。

## 步骤
1. **适用性判定**：Linear 官网风格面向技术型产品、开发者工具、B2B SaaS。若目标是消费级、活泼、电商类页面，直接说明不匹配并停止，不要硬套。
2. **写 3 个风格关键词 + 数值约束**，三者必须能翻译成参数：
   - 暗色原生 → 背景 `#08090a`（非纯黑），正文 `#f7f8f8`（非纯白）。
   - 亮度分层 → 表面色阶 `#08090a → #0f1011 → #191a1b`，边框用 `rgba(255,255,255,0.05~0.08)`，层级不靠投影。
   - 单色强调 → 全页只有一个彩色相（靛紫 `#5e6ad2 / #7170ff / #828fff`），彩色像素占比 < 5%，只出现在 CTA、活跃态、品牌元素。
3. **出 token 表**：语义色（暗色一套，明暗同表则分列）、字号阶梯 ≥ 6 级（含大字号负字距）、间距基数 8px 及档位、圆角 6/8/12/9999px、阴影策略（仅浮层）、动效 120–200ms ease-out 且只动 transform/opacity。
4. **加官网独有的氛围层**：至少给出 1 条代码实现的径向光晕写法（`radial-gradient` + 极低白透明度），并声明渐变只能是亮度渐变，不许彩虹渐变。
5. **组件落地**：用 token 拼出主按钮、卡片、导航各一个，只引用 token 名；出现字面值即回第 3 步补 token。
6. **自检**：是否出现第二个彩色相？是否用了 `#ffffff` 或 `#000000`？是否用投影表达层级？圆角是否 ≤ 12px（胶囊除外）？任一不过，改完再输出。

## 输出格式
- 三段式：**风格定位**（≤ 4 句，含 3 个关键词及数值约束）→ **Token 表**（Markdown 表格）→ **组件与氛围示例**（≤ 4 个片段，每个 ≤ 8 行）。
- 总长度 ≤ 120 行。
- 必须包含：3 个风格关键词、暗色语义色表、字号阶梯（≥ 6 级，标注大字号负字距）、间距基数与档位、圆角档位、动效参数、1 条径向光晕代码、1 个可直接粘贴的 `:root` CSS 变量块、对比度结论。
- 品牌色替换、浅色未覆盖、未验证的对比度，逐项显式标注「待确认 / 未覆盖 / 需工具验证」。

## 不要做
- 不要引入第二个彩色相（成功绿、警告橙等状态色不得进入营销页视觉主体）。
- 不要用 `#ffffff` 做正文白、`#000000` 做最深背景——会摧毁暗色层次。
- 不要用投影表达层级；层级只靠表面色阶 + 半透明细边框。
- 不要把「渐变」理解成彩色过渡，只允许亮度渐变与径向光晕。
- 不要圆角 > 12px（胶囊形 9999px 除外），不要弹跳/弹簧缓动。
- 不要给不匹配的产品（消费级、活泼调性）硬套本风格；不要凭空确定品牌替换色或声称浅色主题已覆盖。
